# ==============================================================
# WHAT WE BUILT
# ==============================================================
# A conversational AI chatbot that:
# - Has a web UI built with Streamlit
# - Uses AWS Bedrock (Amazon Nova Pro) as the AI brain
# - Remembers the conversation history during a session
# - Can be run locally or deployed on AWS EC2


# ==============================================================
# ARCHITECTURE OVERVIEW (Simple Flow)
# ==============================================================
#
#   [ User (Browser) ]
#          |
#          | types a message
#          v
#   [ Streamlit UI - chatbot_frontend.py ]
#          |
#          | calls demo_conversation()
#          v
#   [ LangChain - chatbot_backend.py ]
#          |
#          | builds prompt + chat history
#          v
#   [ AWS Bedrock - Amazon Nova Pro Model ]
#          |
#          | returns AI response
#          v
#   [ LangChain - chatbot_backend.py ]
#          |
#          | saves response to memory
#          v
#   [ Streamlit UI - chatbot_frontend.py ]
#          |
#          | displays response in chat bubble
#          v
#   [ User (Browser) ]
#
# ==============================================================


# ==============================================================
# LAYER 1: FRONTEND - chatbot_frontend.py
# ==============================================================
# Technology : Streamlit
# Purpose    : Builds the web UI that users interact with
# Runs on    : Local machine (port 8501) or EC2
#
# What it does:
# - Shows the chat interface in the browser
# - Takes user input from the chat box
# - Displays user and AI messages as chat bubbles
# - Stores chat history using Streamlit session_state
# - Calls the backend functions to get AI responses
#
# Key Streamlit features used:
# - st.title()          → page heading
# - st.chat_input()     → message input box at the bottom
# - st.chat_message()   → chat bubble (user or assistant)
# - st.session_state    → persists memory and chat history across reruns


# ==============================================================
# LAYER 2: BACKEND - chatbot_backend.py
# ==============================================================
# Technology : LangChain + AWS Bedrock SDK
# Purpose    : Handles all AI logic and AWS communication
#
# What it does:
# - Connects to AWS Bedrock using your AWS credentials
# - Builds the prompt with system instructions + chat history
# - Sends the prompt to the AI model
# - Saves each conversation turn to memory
# - Returns the AI response text to the frontend
#
# 3 Key Functions:
# - demo_chatbot()       → creates the Bedrock model connection
# - demo_memory()        → creates empty chat history list []
# - demo_conversation()  → sends message to AI, updates memory, returns response


# ==============================================================
# LAYER 3: AI MODEL - AWS Bedrock
# ==============================================================
# Technology : AWS Bedrock (Serverless AI service)
# Model      : Amazon Nova Pro (amazon.nova-pro-v1:0)
# Purpose    : The actual AI brain that generates responses
#
# What it does:
# - Receives the full prompt (system + history + user message)
# - Generates a relevant, context-aware response
# - Returns the response back to LangChain
#
# Why Bedrock?
# - Serverless - no AI infrastructure to manage
# - Pay per token (per word processed)
# - Multiple models available (Nova, Claude, DeepSeek, Titan etc.)
# - Secure - uses your AWS IAM credentials


# ==============================================================
# LAYER 4: MEMORY (Conversation History)
# ==============================================================
# Technology : LangChain Core Messages (plain Python list)
# Purpose    : Makes the chatbot remember previous messages
#
# How it works:
# - Stored as a list of HumanMessage and AIMessage objects
# - Each turn adds 2 items to the list:
#     HumanMessage(content="user's question")
#     AIMessage(content="AI's answer")
# - Passed to the model every time so it has full context
# - Stored in Streamlit session_state (lives until browser tab closes)
#
# Example memory after 2 turns:
# [
#   HumanMessage("What is AWS?"),
#   AIMessage("AWS is Amazon Web Services..."),
#   HumanMessage("What services does it offer?"),
#   AIMessage("It offers EC2, S3, Bedrock...")
# ]

# ==============================================================
# SERVERLESS vs SERVER
# ==============================================================
#
# AWS Bedrock (AI)  → SERVERLESS  - no server to manage, pay per request
# Streamlit (UI)    → NOT serverless - needs a running server (local or EC2)
#
# To make it fully serverless:
# - Replace Streamlit with AWS Lambda + API Gateway + S3 frontend
# - But that is much more complex - EC2 is fine for learning
